# #89 共有シートのキャンセル時に「保存しました」トーストを出さない

- **ステータス**: `[ ]` 未着手
- **フェーズ**: 21. 編集 / エクスポート / 布地登録 UX 改善
- **前提**: #85, #87
- **重要度**: 🟡 不具合修正

## 概要

エクスポート画面の「画像として保存」「SVG として保存」ボタンを押した後、共有シートで保存をキャンセルしても **「保存しました」トーストが表示される**不具合を修正する。

ユーザーがキャンセルしているのに「保存」と通知するのは実態と矛盾する。トースト自体を廃止し、共有シートを閉じた = 操作完了とユーザーが視覚的に確認できる UX に変更する。

## 背景 / 動機

- `Sharing.shareAsync` は共有シートのキャンセル時も**正常に resolve する**仕様で、結果コードを返さない(Expo の制約)
- 現状は `await Sharing.shareAsync(...)` 直後に無条件で成功トーストを出している
- 共有シートを閉じた時点でユーザーは結果を視覚的に確認できる(写真アプリ・ファイルアプリで保存先を見れば自明)
- 印刷 PDF キャンセル(#88)の silent 方針とも一貫する

## 受け入れ条件 (AC)

- [ ] 「画像として保存」で共有シートをキャンセル時、「保存しました」トーストが出ない
- [ ] 「SVG として保存」で共有シートをキャンセル時、「保存しました」トーストが出ない
- [ ] 実際に保存した場合も同じく成功トーストは出ない (UX 一貫性)
- [ ] 失敗時(例外発生時)はエラートースト表示が従来通り動作する
- [ ] 既存テストグリーン / 型チェック通過

## 実装方針

### `features/export/ExportScreen.tsx`

`handleExportImage` と `handleExportSvg` の `Sharing.shareAsync` 後の `showToast({ message: t('exportScreen.saved'), variant: 'success' })` 行を **削除**する。

### 翻訳キー `exportScreen.saved` の扱い

他の参照がない場合は削除候補。実装時に grep で確認する。
(参照があれば残す/未参照なら ja/en から削除)

### CLAUDE.md 更新は不要

「成功時にトーストを出す」という明示の仕様記述は CLAUDE.md にないため、本タスクでは CLAUDE.md は更新しない。

## メモ

- `expo-sharing` の API では「共有された/キャンセルされた」を判別できない
- 代替として `react-native-share` 等の外部ライブラリで結果取得は可能だが、Expo の管理範囲外で複雑化するため採用しない
- 印刷 PDF (#88) と同様、「キャンセル = silent 終了」のポリシーを共有シートにも適用する
