# #84 編集画面: パッチワーク外タップで選択解除

- **ステータス**: `[~]` 実機確認待ち

## 概要

パッチワーク編集画面で、キャンバス (PatternCanvas) の **外側** をタップしたときにピースの選択を解除する。
ただし、布地選択パネルやアクションボタン (調整 / 対応付けを解除 など) をタップした場合は選択を維持する
(操作ターゲットを失わせない)。

## 受け入れ条件 (AC)

- [ ] キャンバス外側 (背景余白) をタップ → `selectedPolygonIdAtom` が `null` に戻る
- [ ] 布地選択パネル内をタップ → 選択は維持される
- [ ] アクションボタン領域をタップ → 選択は維持される
- [ ] ヘッダー (戻る・保存・エクスポート・調整) をタップ → 選択は維持される
- [ ] 調整モード中はこの解除挙動は走らない (調整中の誤操作回避)
- [ ] 既存テストグリーン / 型チェック通過

## メモ

- 実装案: キャンバスを囲む親 View に `Pressable`/`onPress` を持たせ、`setSelectedPolygonId(null)` を呼ぶ。
  布地パネル等はこのままで OK (RN の Pressable は通常バブルしない/明示的に止める必要なし)。
- ファイル: `features/editor/EditorScreen.tsx`
