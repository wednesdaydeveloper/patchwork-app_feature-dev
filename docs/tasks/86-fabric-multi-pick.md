# #86 布地管理画面: カメラロールから複数選択

- **ステータス**: `[x]` 完了
- **フェーズ**: 21. 布地管理 UX 改善
- **前提**: #24
- **重要度**: 🟢 機能追加

## 概要

カメラロールからの布地登録時に、複数枚を一括で取り込めるようにする。
キャリブレーションは未設定 (pxPerMm = null) で登録し、各布地で後からキャリブレーションできる導線
(#75 の再キャリブレーションボタン) を活用する。

## 受け入れ条件 (AC)

- [x] カメラロール選択時に **複数選択モード** を有効化 (`expo-image-picker` の `allowsMultipleSelection`)
- [x] 上限 **10 枚** を超えた場合はトーストで通知し、先頭 10 枚のみを採用 (もしくは選択をキャンセル)
- [x] 取り込み時に **共通プレフィックス + 連番** で名前を付ける UI を表示
   - プレフィックス入力欄、カテゴリ入力欄
   - 連番は `01, 02, ...` のゼロ埋め 2 桁
   - 例: プレフィックス `木綿` → `木綿01`, `木綿02`, ...
- [x] プレフィックスが空の場合はデフォルト名 (タイムスタンプ系) を使用
- [x] 登録は `pxPerMm = null` で行う (キャリブレーション工程はスキップ)
- [x] 完了後、布地一覧に追加された旨をトーストで通知
- [x] 失敗時はエラートーストで通知
- [x] **カメラ撮影** の場合は従来どおり 1 枚ずつ + キャリブレーション必須 (本タスクでは変更しない)
- [x] 未キャリブレーション (`pxPerMm == null`) の布地アイテムにサムネイル右上に **⚠️ バッジ** を表示
   - 一括登録された布地が後から個別にキャリブレーションが必要なことを直感的に示す
   - バッジは表示のみ (タップでキャリブレーション直行はしない、既存の編集 → キャリブレーション導線を流用)
   - ファイル: `features/fabrics/FabricsScreen.tsx` の布地アイテムレンダリング部
- [x] 既存テストグリーン / 型チェック通過

## メモ

- 実装ポイント:
  - `expo-image-picker.launchImageLibraryAsync({ allowsMultipleSelection: true, selectionLimit: 10 })`
  - `useFabricRegister` フックの状態モデルを「単数 pending」から「複数 pending リスト」に拡張、
    あるいは「複数選択時専用」のフローを別途用意
  - 一括登録ダイアログ (新規) でプレフィックス/カテゴリを入力 → `addFabricAtom` を逐次呼び出し
- pxPerMm = null の布地は描画時に cover フォールバックされる (PieceImage の既存仕様)
- ファイル: `features/fabrics/useFabricRegister.ts`, `features/fabrics/FabricsScreen.tsx`,
  および新規 `features/fabrics/BulkPrefixDialog.tsx` 程度
