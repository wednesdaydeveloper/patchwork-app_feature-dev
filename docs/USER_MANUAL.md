> パッチワークのパターンと布地画像を組み合わせて、デジタルパッチワーク作品を作成・管理するモバイルアプリです。
> このマニュアルは一般ユーザー向けの操作説明書です。

## 1. はじめに

### このアプリでできること

- 用意されたパッチワークパターン (ナインパッチ、バリアブルスター 等) を選んで作品を作る
- カメラやカメラロールから登録した布地画像をピース 1 つ 1 つに割り当てる
- ピースごとに布地の位置・回転をきめ細かく調整する
- 完成した作品を画像 (PNG / JPEG) や印刷用 PDF として出力する
- 複数の作品を保存し、後から編集を再開する

### 対応端末

- **iPhone / Android スマートフォン**: 縦向き
- **iPad / Android タブレット**: 横向き
- インターネット接続は不要 (オフラインで完結)

> 📸 **スクリーンショット推奨**: アプリアイコン / スプラッシュ画面 (アプリの第一印象を伝える1枚)

## 2. アプリの起動と初期設定

### 起動時の言語

端末の言語が「日本語」のときは自動的に日本語で表示されます。それ以外の言語のときは英語で起動します。
あとから [設定画面](#9-設定) で切り替え可能です。

### ホーム画面

起動するとホーム画面が表示されます。次の操作ができます。

| 操作 | 効果 |
| --- | --- |
| **新規パッチワーク** ボタン | パターン選択画面へ移動 |
| **布地** リンク | 布地管理画面へ移動 |
| **設定** リンク | 設定画面へ移動 |
| 一覧の作品をタップ | 編集画面で開き直す |
| 作品の左スワイプ | 削除メニューを表示 |

> 📸 **スクリーンショット推奨**: ホーム画面 (作品一覧が数件入った状態)

## 3. 布地を登録する

布地画像を登録しないと、ピースに対応づけることができません。**最初に必ず数点の布地を登録してください。**

### 登録手順

1. ホーム画面の **布地** をタップ
2. 「布地を登録」のような追加ボタン (＋) をタップ
3. 撮影方法を選ぶ
   - **カメラで撮影**: 端末カメラで布地を撮影する
   - **カメラロールから選択**: 既に持っている画像を使う
4. 画像が読み込まれたら、**名前** と **カテゴリ** (任意) を入力
5. 続けて **キャリブレーション** を行う ([次のセクション](#キャリブレーションについて) を参照)

> ⚠️ 初回利用時はカメラ・写真ライブラリへのアクセス許可が求められます。許可しないと布地登録ができません。

### キャリブレーションについて

「キャリブレーション」とは、布地画像が **実寸でどのくらいの大きさか** をアプリに教える作業です。
これを正しく行わないと、印刷出力や実寸プレビューで布柄の大きさがズレます。

1. キャリブレーション画面で、画像の上に表示される **ルーラ (定規)** を見ます
2. 画像のうち実寸で「**100mm**」になる範囲を指でピンチ操作してルーラに合わせます
3. 完了ボタンを押すと登録完了です

> 後から [布地管理画面](#布地一覧の操作) → 各布地の編集メニューから **キャリブレーション再実行** が可能です。

### 布地一覧の操作

| 操作 | 効果 |
| --- | --- |
| 布地をタップ | 名前・カテゴリ編集 |
| 布地を左スワイプ | 削除 |

> ⚠️ 既存の作品で使われている布地を削除しようとすると警告ダイアログが出ます。強制削除するとその布地が割り当てられていたピースは「未割り当て」に戻ります。

> 📸 **スクリーンショット推奨**:
> - 布地登録方法選択 (カメラ / カメラロール の選択肢)
> - キャリブレーション画面 (ルーラと布地が重なった状態)
> - 布地管理画面 (数点登録された一覧)

## 4. パッチワークを新規作成する

### パターンを選ぶ

1. ホーム画面の **新規パッチワーク** ボタンをタップ
2. パターン選択画面でグリッド表示されたパターン一覧から好きなものをタップ
   - ナインパッチ、バリアブルスター 等のテンプレートが並びます
3. パターンが決まったら **サイズ指定画面** が開きます

### サイズを決める

- パッチワーク 1 枚の **一辺の物理サイズ (mm)** を指定します
- 範囲: **50〜280mm** (初期値 150mm)
- 印刷出力時の実寸はここで決まります

決定すると **編集画面** が開きます。

> 📸 **スクリーンショット推奨**:
> - パターン選択画面 (グリッド表示)
> - サイズ指定画面 (スライダーや数値入力欄)

## 5. ピースに布地を対応づける

編集画面ではパッチワークのパターン全体が表示されます。

### 基本操作

1. 対応づけたいピースを **タップ** して選択する (枠が強調表示される)
2. 画面下部 (タブレットでは右側) の **布地選択パネル** から布地をタップ
3. 選択中のピースに布地が貼り付きます
4. 別のピースをタップして同様の操作を繰り返します

### 同じ布地を複数のピースに使う

同じ布地を別のピースに割り当てても問題ありません。

### 対応づけを解除する

- 編集画面下部の **「対応付けを解除」** ボタンをタップすると、選択中のピースから布地が外れます
- 布地が割り当てられていない時はボタンは押せません (グレーアウト)

> 💡 「調整」「対応付けを解除」ボタンは布地の割当有無に関わらず常に表示され、未割り当て時は無効状態 (薄く表示) になります。

> 📸 **スクリーンショット推奨**:
> - 編集画面 (ピース未選択)
> - 編集画面 (ピース選択中、強調表示あり)
> - 編集画面 (布地が複数のピースに対応づけられた状態)

## 6. 布地の位置・回転を調整する

ピースに対して布地のどの部分を見せるか、向きを変えるかを細かく調整できます。

### 調整モードに入る

1. 調整したいピースを **タップ** して選択
2. **「調整」** ボタンをタップ
3. 画面が拡大表示に切り替わり、布地選択パネルは隠れて調整に集中できる UI になります

### 調整できる項目

| 操作 | 効果 |
| --- | --- |
| **指 1 本ドラッグ (パン)** | ピース内での画像表示位置を移動 |
| **指 2 本でひねる (回転)** | 画像を回転させる |
| **リセット** ボタン | 調整値を初期化 (中央配置・回転 0°) |

> 💡 ピンチ操作 (拡大縮小) ではなく、回転だけが可能です。布地は実寸キャリブレーションに従って表示されます。

### 調整を確定する

**「調整完了」** ボタンをタップすると元の編集画面に戻ります。調整値はピースごとに独立して保存されます。

### Undo / Redo

編集画面では直近 **20 操作** までやり直し / 取り消しできます。
- 対応づけ
- 対応づけ解除
- 位置・回転調整

作品を切り替えたり保存後に再度開いたりすると履歴はクリアされます。

> 📸 **スクリーンショット推奨**:
> - 調整モード画面 (ピースが大きく表示され、布地選択パネルが消えた状態)
> - リセット / 完了ボタンの位置がわかる構図

## 7. パッチワークを保存・編集再開する

### 名前を付けて保存

1. 編集画面のヘッダーにある **保存** ボタンをタップ
2. 名前入力ダイアログが出るので、作品名を入力 (空欄なら「無題」になります)
3. **保存** で確定

### 編集を再開する

ホーム画面に戻ると一覧に作品が並びます。タップで編集を再開できます。

### 名前の変更

編集画面のヘッダーで作品名をタップするとリネームダイアログが出ます。

### 削除

ホーム画面で作品を **左スワイプ** → 削除をタップ。確認の上で削除されます。

### 未保存変更の警告

作品を編集中に画面を離れようとすると「変更を保存しますか?」のダイアログが表示されます。

> 📸 **スクリーンショット推奨**:
> - 保存ダイアログ (名前入力中)
> - ホーム画面の作品一覧 (複数件)
> - 未保存変更の離脱ガードダイアログ

## 8. 作品をエクスポートする

完成した作品を画像 / PDF として出力できます。

### エクスポート画面の開き方

編集画面のヘッダーから **エクスポート** ボタンを押します。

### 画像で保存 (フォトライブラリ)

1. **画像形式** を選ぶ (PNG / JPEG)
   - PNG: 透明背景対応、ファイル容量大
   - JPEG: 白背景、ファイル容量小
2. **保存** をタップ → カメラロール (フォトライブラリ) に書き出されます

> ⚠️ 初回利用時はフォトライブラリへの書き込み許可が求められます。

### 印刷用 PDF を出力

1. **用紙サイズ** (A4 など) を選ぶ
2. **PDF 出力** をタップ
3. 共有メニューが開きます。プリンタやファイル保存先を選んでください

PDF は **実寸印刷** に対応しています。プリンタ側で「実寸 (100%)」設定にすれば、紙の上で `Work.sizeMm` で指定したサイズで印刷されます。

> 📸 **スクリーンショット推奨**:
> - エクスポート画面 (画像 / PDF オプション一覧)
> - 出力された PDF のサンプル (1 ページ全体)

## 9. 設定

### 言語切替

ホーム画面 → **設定** から **日本語 / English** を切り替えます。
変更後すぐに UI が切り替わり、選択は次回起動時にも引き継がれます。

> 📸 **スクリーンショット推奨**: 設定画面 (言語選択ラジオ)

## 10. 困ったとき

| 症状 | 対処 |
| --- | --- |
| 布地が登録できない | カメラ / 写真ライブラリのアクセス許可を端末設定で確認 |
| 作品の保存に失敗する | 端末ストレージの空き容量を確認。50MB 未満で警告、5MB 未満で停止 |
| 作品の読み込みに失敗する | エラーダイアログで OK を押すとホームに戻ります。作品データが破損している可能性 |
| 布地を削除しようとすると警告 | その布地は既存作品で使用中。強制削除すると関連ピースが未割り当てに戻ります |
| 印刷が実寸サイズにならない | プリンタ印刷設定で「実寸 (100%)」「ページに合わせる OFF」になっていることを確認 |
| パターン一覧が表示されない | アプリの再インストール (内部データ破損の可能性) |

### エラー通知の見分け方

- **トースト (画面下部に一時表示)**: 軽度のエラー、操作を続行可能
- **ダイアログ (画面中央に表示)**: 重要なエラー、復帰手段を選ぶ必要あり

## 11. 用語集

| 用語 | 定義 |
| --- | --- |
| ピース | 直線・曲線で囲まれた、パターンを構成する 1 つの図形 |
| パターン | 1×1 の正方形をピースで埋め尽くしたテンプレート (例: ナインパッチ) |
| 布地 (ファブリック) | ピースに割り当てる画像データ |
| 対応づけ | ピースと布地を関連付ける操作 |
| パッチワーク (作品) | パターンに布地を対応づけて完成した 1 つの作品 |
| キャリブレーション | 布地画像を実寸サイズと結びつける作業 (1mm あたりピクセル数を測定) |
| 調整モード | ピース内での布地の位置・回転をきめ細かく操作できるモード |
